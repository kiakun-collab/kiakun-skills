# Level 3 Delivery Checklist

- [ ] Level 2 全部通过；校准成本跟随 executionProfile，不因 C 强制 strict。
- [ ] 约定范围内的背景、人物、内容图独立，其他必须编辑对象符合约定边界。
- [ ] assetAuditFile 覆盖指定资产，真实 alpha 和实际叠加边缘通过检查；独立图片对象数量不作为抠图完成证据。
- [ ] 待人工抠图时标 MANUAL_CUTOUT_REQUIRED 并提供素材和替换位置；不勾选完整 Level 3 通过。
- [ ] 拆层后的构图、字体、位置、层级与边缘融合通过最终渲染验证。
- [ ] level3Gates 七项有自动证据、实际视觉观察及最终状态。
- [ ] 不可拆分例外已经获允许并记录；不存在暗改 B 或烘焙必须编辑对象。
- [ ] 修复页用新预览，重大偏差与阻断项为零；minor 和剩余限制明确记录。
