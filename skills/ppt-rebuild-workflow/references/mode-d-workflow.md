# Mode D Workflow

用于参考图语义错误、内容归属错误、误增模块、误删信息或阅读顺序错误的任务。Mode D 只重做参考图，不创建 PPTX。

## 输入

- 原 PPTX、原文案或可信业务文档。
- 有问题的参考图。
- 必须保留的信息和禁止新增的信息。
- 用户偏好的视觉方向。
- 候选图数量和输出目录。

## 流程

1. 从可信来源建立页面事实清单：原文、图片归属、阅读顺序、必需模块。
2. 建立问题清单：错字、错配、遗漏、虚构元素、层级错误和版式误导。
3. 写候选图生成规格，明确哪些视觉可变、哪些语义不可变。
4. 生成 2-3 个候选方向；同一轮只改变已声明的视觉变量。
5. 逐张执行语义验收，不通过的候选不得进入用户选择。
6. 让用户选择候选或提出定向修改。
7. 冻结选定参考图、准确文案、页序和资产归属。
8. 根据可编辑边界转入 Mode B 或 Mode C。

## 语义验收

- 文案与可信来源一致。
- 没有新增未经授权的业务模块、人物、数据或关系。
- 图片与文字归属正确。
- 阅读顺序清楚。
- 视觉强调符合页面一句话表达。
- 候选图适合后续拆成无字底图或分层资产。

## 下游交接

交付给 Mode B/C：

- 选定参考图路径。
- 冻结文案和页序。
- 页面语义说明。
- 资产归属和可编辑边界。
- 已知生成瑕疵与禁止继承项。

用户未选定候选图或语义验收未通过时，不得开始 PPTX 构建。
