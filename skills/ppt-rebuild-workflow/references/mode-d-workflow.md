# Mode D Workflow

仅用户明确要求新的设计方向时进入，不能因为错字、OCR 不确定、速度优化或局部语义修正自动触发。

D 是设计阶段，后续输出在路由时明确为 A/B/C；如果用户只要参考图则停止于 D。E 中局部设计只作用于指定范围。

1. 从来源固定准确文案、模块、图片归属和阅读顺序。
2. 按用户要求调整可变的风格/构图，保留事实与必须内容。
3. 默认一个方向；用户要求多个候选才生成对应数量。语义与资产策略通过后再进入重构。
4. 用户说“我来选”则等待选择；已经要求自行定稿/完成全流程则自动选定符合要求的方向并继续，不强加确认关卡。
5. 冻结选定参考与文案，按既定编辑范围生成 PPTX。

候选图中的文字仍可能错误，以来源文案作为重构事实。图像生成遵循当前可用工具和用户授权。
