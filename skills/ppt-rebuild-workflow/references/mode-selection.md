# Mode Selection

## 决策顺序

1. 用户是否已经手工修改过 PPTX 且只要求局部替换或修正？是：Mode E。
2. 参考图是否语义错误、误增模块、误删内容、错解关系，或用户是否明确要求改版提升？是：Mode D。
3. 用户是否只要快速平铺预览或方向讨论、不要可编辑？是：直接产出**纯图片基线 deck**（Mode A 的本质：每页一张完整图铺满，不需参考测量），不进重构。
4. 用户是否允许背景和主视觉合成，但要求文字、标签、正文框、页码和装饰线可编辑？是：Mode B。
5. 用户是否要求人物、背景和内容图都能分别移动或替换？是：Mode C。

Mode E 是修改策略，优先于可编辑程度分类；当前磁盘 PPTX 是最高优先级。Mode D 在参考图语义需要先修正，或用户明确要求创建更好的新视觉方向时优先。其余场景中，速度和可编辑性并存时建议 Mode B，长期复用和深度编辑时建议 Mode C。

路由反例：用户已经手工修改 PPTX，只要求更换背景，即使同时要求文字可编辑或人物分层，也必须先进入 Mode E。

## 模式边界

### Mode A 纯图片基线 deck

Mode A 本质就是"做一份纯图片 PPT"——把每张参考图整页铺满嵌入 16:9 deck，**不需要参考测量、坐标校准或视觉抽取**。它不再是与 B/C 并列、需要独立判定的重构模式，而是两种角色：

- **独立交付物**：用户只要平铺预览/方向确认时，这份纯图片 deck 就是交付结果。
- **重构对照基线（B/C 必建，见文末硬约束）**：Mode B/C 重构前必须先产出并渲染这份基线，作为编辑版还原度的 PPT 原生对照目标。

约束：允许整页图铺满；禁止声称文字和结构可编辑；作独立交付时 QA Level 1，作基线时随宿主 B/C 一起判。

### Mode B 半可编辑重构

- 默认启用 `auto-calibrated`：自动测量、坐标锁、临时校准层、渲染回看，不要求用户逐页确认锚点。
- 允许烘焙：背景环境 + 主视觉人物或场景。
- 禁止烘焙：标题、正文、标签、页码、装饰线、正文框、边框。
- QA：Level 2，重点检查文字和结构可编辑。

### Mode C 高还原完全分层重构

- 默认启用 `auto-calibrated`；复杂不稳定分层若无法稳定实现，自动降级到边界内 `baked-asset` 或 Mode B fallback，并记录，不能声称完整 Mode C 通过。
- 默认：纯背景、人物透明 PNG、内容图、文字、形状独立。
- 只有主体与环境确实不可拆分时，才允许一张核心视觉图，并在 asset-audit 中说明。
- QA：Level 3。

### Mode D 先重做参考图

- 只生成候选参考图，不创建 PPTX。
- 至少检查原文、原图、阅读顺序、内容归属和新增元素。
- 只有用户明确要求改版、优化或升级时，才把“比原参考图更好”作为新目标；单纯重构不得自动进入该目标。
- 用户选定后再进入 Mode B 或 Mode C。
- 完整流程见 [mode-d-workflow.md](mode-d-workflow.md)。

### Mode E 增量修改

- 当前磁盘 PPTX 是最高优先级。
- 必须备份并记录哈希。
- 只替换目标对象，另存新文件。
- QA：Level 4。

### 坐标系与比例

- 可编辑坐标系只覆盖 16:9（默认 1280 x 720）。非 16:9 输入不做扩展坐标规范：走 Mode A 整页图，或经用户确认后按等比映射进 1280 x 720（留黑边或裁切由用户选）。

## 重构对照基线（Mode B/C 硬约束）

Mode B/C 编辑重构**必须**先建立纯图片基线 deck 并对照，不是可选步骤：

1. **建基线**：从参考图产出纯图片基线 deck（Mode A 本质，每页整页图铺满），用与最终交付**同一个渲染后端**渲染为 `baseline-render/`（同画布、同渲染器）。
2. **先过基线门**：把基线渲染图与参考图做一次对照——若纯图片基线都渲染不对（尺寸、色彩、裁切异常），先修环境/渲染后端，再谈重构；这是兜底地板。
3. **编辑版对照基线**：Mode B/C 的编辑版渲染，除对照原始参考图外，**必须再对照 `baseline-render/`** 过还原度门禁。基线对照是同后端同画布的 apples-to-apples 比较，消除"源图/浏览器 vs PPT 渲染"的尺度与渲染器差异，是编辑版是否忠实的主判据。
4. **硬门禁**：未建立基线 deck、未跑基线对照，或基线对照未过，**不得把 Mode B Level 2 / Mode C Level 3 标记为完整通过**。

工具复用：基线渲染与对照直接用 `calibrate_reference_render.py` / `make_reference_render_comparison.py`，`baseline-render/` 只是又一个对照图目录，无需新脚本。
