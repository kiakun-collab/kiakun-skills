# Visual Overlap QA

## 目的

对象坐标和文本框边界不能完整代表最终文字结果。字体度量、行高、阴影、描边、透明度、抗锯齿、图片高对比边缘以及细装饰线，都可能造成“参数通过、文字不可读”。

因此，几何审计是预检，最终渲染的图像识别审计是交付门禁。

本文件只定义文字可读性门禁。页面是否达到参考图的版式、构图、层级、色彩和整体观感，按 `visual-fidelity-qa.md` 另行审计。两项构成视觉 QA 双门禁。

## 双层检查

### 第一层：几何预检

- `textFrameIntersections = 0`。
- 检查细长非文本形状与文本框的相交候选，尤其是 `decor-line-*`、`footer-line-*`、`border-*`。
- 面板、标签底板等用于承载文字的形状可以与文字框重合，但必须有明确角色。
- 未命名的细长形状与文字框相交时，默认视为风险，进入视觉复核。

### 第二层：图像识别审计

- 使用最终导出的逐页 PNG，而不是构建前截图或旧预览。
- contact sheet 用于发现批量异常；每页必须查看全尺寸图。
- 采用整页优先：先查看整页原图，再放大整页到能辨认字形边缘和线条间距。
- 不得把多轮裁剪作为默认审计流程。孤立裁剪会切断连续线条、大面积图片和跨区形状，不能单独用于 PASS/FAIL。
- 放大整页只用于判断文字是否清晰、完整、被遮挡或裁切；AI 伪字和错字的准确内容按 `text-recovery.md` 恢复。
- 修复后必须重新导出 PNG，并对修复页和相邻页面复审。

图像识别审计拥有否决权。即使所有机器指标为零，只要图中存在影响文字可读性的碰撞，QA 仍为失败。

形状与形状、图片与图片、图片与非文字形状之间的叠放是常见设计手段，不纳入通用碰撞门禁。只有它们影响标题、正文、标签、页码或其他文字的辨识、完整性和阅读顺序时才记录为视觉重叠问题。

## 必查冲突

- 装饰线、分隔线、页码线穿过标题、副标题、标签或正文。
- 边框、标签轮廓压住字形。
- 两组文字字形互相覆盖或视觉相切。
- 图片、人物、船桅、建筑等高对比边缘切过文字，造成类似遮挡。
- 阴影、描边、发光范围侵入相邻文字。
- 文字与线条虽未实际交叠，但安全间距过小，在正常缩放下看起来粘连。
- 文本框未相交，但字形因字体替换、字号、粗体或行高超出预估区域。
- 文字越过正文框、标签或其他承载容器的边界，或在画布边缘被裁切。

正常情况不应误报：正文位于半透明底板内、标签文字位于标签底形内、标题叠在可读背景区域上。

## 差异热力图的边界

绝对差异热力图逐像素计算参考图和渲染图的颜色差，并用亮度或伪彩色显示差异强度。它是确定性图像运算，不依赖模型判断，但只适合筛选候选区域。

- 仅在两张图尺寸、裁切和位置严格一致时使用。
- 可发现明显位移、缺失对象、颜色变化和大范围构图差异。
- 字体抗锯齿、渲染引擎、压缩、阴影和亚像素偏移会产生大量无害差异。
- 热力图不能理解语义，无法判断差异是错误、允许偏差还是有意重构。
- 热力图不得单独决定 PASS/FAIL；候选区域必须回到并排整页原图复核。

## 放大检查的边界

放大整页用于观察渲染质量，不用于恢复 AI 图像模型已经生成错误的字符。

- 优先放大整页，保留阅读顺序、跨区线条、图片边界和形状关系。
- 不使用孤立裁剪图判断连续线条、大面积图片、跨区形状、旋转对象或整体构图。
- 若整页图无法稳定判断文字是否发生遮挡或裁切，设置 `needsHumanReview = true`，不继续多轮裁剪。
- 若问题是字本身错误、乱码或伪字，转入文字语义恢复，不在视觉重叠审计中猜字。

## 报告格式

每个问题记录：

- `page`
- `region`：左上、标题区、副标题区等，必要时给像素框。
- `text`
- `conflictingElement`
- `severity`：blocker / major / minor
- `evidence`
- `recommendedFix`
- `status`：open / fixed / verified

总报告必须包含：

- `visionAuditStatus`
- `visualOverlapCount`
- `flaggedPages`
- 审计使用的渲染目录
- 复审渲染目录

Level 2 和 Level 3 交付要求 `visionAuditStatus = PASS`、`visualOverlapCount = 0`。这里的 `visualOverlapCount` 只统计影响文字可读性的碰撞，不统计正常的形状或图片叠放。

不统计通用碰撞不等于忽略视觉还原。普通对象的叠放、位置或层级若明显偏离参考图，应记录为还原度偏差，而不是文字碰撞。

## 冲突出口

出现以下任一情况时停止自动返修循环：

- 连续两轮对同一区域的结论矛盾。
- 同一区域反复在 FAIL 和 PASS 之间切换。
- 模型无法稳定判断字形、线条或图片边缘是否构成碰撞。

此时设置 `needsHumanReview = true`，保存原渲染、标记图、复审图和两轮审计记录，并请求人工裁决。人工结论写入 `manualEvidence` 后才能关闭该问题。
