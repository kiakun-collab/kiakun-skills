# Incremental Edit Workflow

用于用户已经修改过 PPTX，只需要局部替换或修正的任务。

## 硬规则

- 当前磁盘 PPTX 是唯一源文件和最高优先级。
- 开始前复制备份并记录哈希。
- 不重新运行旧整页构建脚本。
- 不覆盖原文件。
- 只替换目标对象，其他文字、形状、位置和用户改动保持不变。

## 流程

1. 复制备份。
2. 记录源文件哈希。
3. 导出当前渲染，作为修改前对照。
4. 读取对象清单、关系 ID、坐标、裁切、层级。
5. 定位目标对象。
6. 删除或替换目标对象。
7. 插入新背景、人物或目标视觉。
8. 保持原有文字、形状和小图在正确层级。
9. 另存新文件。
10. 对比修改前后对象数量、文字内容和坐标。
11. 执行 Level 4 QA。

## 最终报告必须证明

- 原文件存在。
- 备份存在。
- 新文件存在。
- 用户文字没有丢失。
- 用户形状没有丢失。
- 用户位置修改没有被覆盖。
- 透明形状没有无依据新增。
