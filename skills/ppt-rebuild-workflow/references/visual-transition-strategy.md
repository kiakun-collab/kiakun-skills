# Visual Transition Strategy

用于处理图片边缘渐隐、背景融合、光晕、雾气和明暗过渡。先判断过渡类型，再决定使用原生形状还是图片；不要在构建后用窄矩形反复补缝。

## 三级策略

### 1. 简单规则渐变

同时满足以下条件时，使用 PPT 原生渐变形状：

- 过渡两侧是纯色或近似均匀色。
- 过渡方向明确，可用线性或径向渐变表达。
- 没有需要延续的纹理、光斑、雾气或不规则轮廓。
- 渐变不会承担图片本身的单侧透明蒙版。

使用 3 至 6 个渐变节点控制颜色、位置和透明度。必须从最终渲染确认方向、宽度和透明度；不能只看构建参数。

### 2. 复杂氛围过渡

出现纹理、光晕、雾气、不规则明暗、人物发丝、图片单侧渐隐或多层空间关系时，使用透明图片或无字底图完成融合。

- 将过渡视为视觉资产的一部分，在图片处理阶段完成单侧透明度和边缘羽化。
- 素材裁切边界不得落在可见过渡区；图片应覆盖完整过渡，或在到达边界前自然衰减为透明。
- Mode B 可把背景环境、主视觉和复杂过渡合成无字底图，文字、标签和结构仍保持可编辑。
- 主视觉必须独立可替换时，可增加一张局部“过渡桥接图”放在主视觉下方；不要因此嵌入整页参考图。

### 3. 混合方案

图片负责真实纹理和透明边缘，原生渐变只用于轻微校色或统一明暗。原生形状不得承担修复错误裁切或错误底色的主要责任。

## 决策规则

- 简单规则渐变：优先原生形状。
- 复杂氛围过渡：优先透明图片或无字底图。
- 同一区域需要两个以上补救蒙层，或修复一轮后仍出现接缝：停止叠加形状，返回资产阶段。
- 图片底色与页面底色明显不同：先处理图片颜色和透明边缘，不用窄矩形渐变遮住边界。
- PowerPoint 的图片柔化边缘会同时影响多个边，不等同于可控的单侧透明蒙版。

## Layout Spec

每个关键过渡区写入 `visualTransitions`：

- `id`：过渡区名称。
- `bounds`：参考图中的 `x/y/w/h`。
- `complexity`：`simple`、`complex` 或 `hybrid`。
- `strategy`：`native-gradient`、`baked-alpha-image` 或 `hybrid`。
- `direction`：左右、上下、径向或不规则。
- `transitionWidthPx`：参考图中实际过渡宽度。
- `sourceAsset`：承担过渡的图片或形状。
- `editableBoundary`：哪些内容烘焙，哪些内容保持可编辑。
- `rationale`：选择该策略的原因。

## QA 门禁

- 使用参考图与最终渲染图的全尺寸并排图检查边缘融合。
- `visibleAssetSeamCount = 0`。
- 逐页记录 `visualTransitionByPage` 和 `transitionFlaggedPages`。
- 明显矩形接缝、色带、突然中断的纹理或错误渐变方向属于 `major`。
- 轻微且不改变页面整体氛围的差异可记为 `minor`。
- QA 发现接缝时，优先检查素材裁切、底色、透明边缘、渐变方向和过渡宽度；不要默认继续增加蒙层。
