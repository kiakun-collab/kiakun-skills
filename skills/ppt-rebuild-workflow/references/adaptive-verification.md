# 按风险验证与减少重复工作

默认 balanced；fast 与 balanced 的通过标准相同，差异是返修预算。strict 增加完整计算校准。

## 一次抽取，三种证据

| 问题 | 优先证据 | 升级条件 |
| --- | --- | --- |
| 文案是否正确 | 用户本次定稿优先；未提供部分取当前 PPTX/业务原文或截图 | 只升级未覆盖部分的数字、专名、否定词、低清字和来源冲突 |
| 位置/换行是否正确 | 原 PPTX 参数、图像 bbox、坐标换算、包内检查 | 变换未知、明显漂移、特殊字体、溢出 |
| 画面是否像且可读 | 最终逐页渲染与参考图同屏对照 | 复杂边缘、遮挡、构图或层级疑点 |

同一模型重复确认不是独立证据。模型置信度不是校准概率；不用单一 0.75 分数决定质量或编辑范围。OCR 是候选，不能理解 AI 伪字，不是唯一事实源。普通单页无需另装服务或引入云端 OCR。

首轮固定文案与对象清单，后续按 ID 检查差异，不再全页重新识别。一次看图同时记录可读性和还原度，两项状态仍独立。

## 低成本默认路径

- 一次整页抽取文字、表格、结构和图片 bbox，生成 layout-spec。共享 style-spec，逐页记录偏移。
- 指定字体且可用就直接用；否则选本地支持字符集的字体，通过初版验证字高、换行和裁切。
- 先构建与渲染，再校准；无需先造临时 deck。
- 每页 renderVerification 记录 page、renderPath、reviewer、observations、coordinateStatus、typographyStatus、triggeredChecks、unresolvedItems。
- 不需要专项校准时 coordinateCalibration.status = NOT_REQUIRED，写原因和渲染证据，不伪称计算 PASS。
- 触发专项时只校准对应页/样式。triggeredChecks 每项含 kind（coordinate/typography）、reason、evidenceFile，指向对应计算脚本 PASS 结果。
- strict 保留全页测量、坐标匹配和主要样式字体探针；不足 3 个锚点记录 INCONCLUSIVE，不凑数。

## 只解决疑点

整页提供构图上下文；一个疑点可追加一次带上下文的局部高分辨率查看或可用 OCR。局部视图不独立证明整页 PASS，也不能从 AI 伪字恢复原本不存在的正确字符。

证据冲突先分类：文案回来源；几何回测量；画面回最终渲染。关键文字仍歧义则集中问一次，继续无关工作。两次模型观感不同不自动转成所有页面人工校对。

## 复用、并行与停止

- 复用原 PPTX 文本和素材，不先栅格化再 OCR。
- 素材优先：原件 → 独立裁切区域 → 原生图形 → 必要生图。纯几何页不强制无字底图；生图期间搭建文字结构。
- 每张生成素材返回即检查 alpha；首次不透明按 asset-policy 交接，停止仅为透明通道重复生成主体。主体身份和产品细节不能因重试不断漂移。
- 以页/素材依赖推进：先做不依赖图片的文字、图表及简单页，素材就绪再填入；不要设置“全批素材成功”后才能构建的门槛。平台支持时可小批并行独立生成；保留各次计时，不保证服务端实际并行。
- 抽取结果是唯一事实表，layout/style/QA 引用它，避免重复手写坐标。
- 只复用确实一致的跨页组件。缓存依赖包括输入内容、文案、字体文件/版本、样式、文本框、画布、渲染器版本；变化则受影响证据失效。旧预览不能验收新 PPTX。
- 包内与几何检查可并行；构建、渲染、校准依赖顺序不变。
- 初版第 0 轮；fast / balanced / strict 返修上限 1 / 2 / 3。通过即停，minor 不强制重做。
- 同问题定向修改仍无改善，换证据或实现方式，不能盲调三轮或烘焙必须可编辑对象。
- 记录各阶段 elapsedMs、renderCount、probeRenderCount、imageGenerationCount、repairedPages。无实际计时不得宣称快了几倍。
- 使用 execution-runner 的事件日志记录成功与失败，阶段时长有重叠时不能相加当整轮耗时。共享读取/代码时间不伪分摊给每页。默认 standard 交付；benchmark 才整理完整跨题对比。
