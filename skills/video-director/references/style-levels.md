# 热门风格进阶

热门风格之所以热门，是因为观众喜欢。不需要回避，但要比"一句话做出来的版本"做得更好、更丰富。

背景：233 条刷屏视频中，66% 是用一句话做出来的，配色、网格、结尾 logo 大量撞脸。观众已经见过很多基线版本，同样的风格，只有做得更细、更满才能留住人。

这份清单靠观察积累：刷到做得好的就补一条进阶做法。用户自己的补充写在 `~/.video-director/style-levels.md`。

## 各风格：基线版 → 进阶做法

| 风格 | 一句话基线版（观众见过太多） | 进阶做法（至少选 2 条） |
|---|---|---|
| 深色发光知识片 | 黑底、青紫光晕、粒子汇聚成字 | 光有来源和方向，只打在主体上；粒子本身有意义（每颗是一个 token、一个人）；暗部有层次，不是纯黑；加入镜头推拉和景深 |
| 瑞士网格排版 | 米白底、红黑配色、左对齐、色块擦除 | 网格本身参与叙事（格子就是数据）；加入印刷质感（纸纹、套色偏移）；节奏有快有慢，留出停顿；字体做出对比 |
| 赛博霓虹 | 品红加青、扫描线、故障效果 | 故障只出现在剧情转折处；加入真实城市或界面素材；霓虹光照亮周围环境 |
| 3D 玻璃 / 渐变 | 毛玻璃卡片、彩虹流体、缓慢旋转 | 材质有真实的折射和焦散；物体和内容有关；镜头有运动设计，不只是转圈 |
| 终端 / 代码 | 绿字黑底、打字机效果 | 显示的是真实可读的代码或日志；打字节奏有人味（停顿、删改）；和画面里的其他元素联动 |
| 数据可视化 | 数字从 0 滚动、环形进度条 | 一个镜头只讲一个数字；用实物比喻（33 场 = 33 块积木）；数字出现的时机卡在声音上 |

## 不论什么风格都能用的丰富度维度

每条片子至少在 3 个维度上超过基线：

1. **内容**：有具体的例子、人物、真实数据，而不是泛泛的概念
2. **声音**：配乐卡点、动作有音效、有配音或环境声（没有声音的片子很难过基线）
3. **镜头**：推、拉、摇、景深变化，而不是固定机位加淡入淡出
4. **质感**：纹理、颗粒、阴影、印刷或手作痕迹，避免过于干净的"矢量感"
5. **节奏**：快慢对比、停顿和留白、高潮位置
6. **细节**：第二遍看才会注意到的小东西（背景里的彩蛋、元素之间的联动）
7. **标志性元素**：系列内固定的角色、转场或结尾动作
